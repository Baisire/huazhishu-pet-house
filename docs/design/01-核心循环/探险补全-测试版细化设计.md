## 1. 范围

**做**：

1. **双槽**：短槽（10m / 30m / 2h）+ 长槽（2h / 8h）。短槽 **Lv2 开放**（贴文档 1.3，用户拍板），长槽 Lv4 解锁；Lv1 阶段探险入口置灰提示「Lv2 解锁探险」。两槽并行结算互不干扰；派遣面板两槽位卡片式展示，各有倒计时与领取态。
2. **照片卡 + 图鉴最小版**：结算按文档掉落率（15%/25%/40%/60%）随机得照片卡；首批 **12 张**占位卡（代码绘制：名称 + 主色块图案，如「窗台日光」「轮中疾跑」「纸箱打盹」）；重复卡自动折算 **+20 瓶子**（toast 说明）；探险面板加「派遣 / 图鉴」页签，图鉴展示 12 格收集进度。
3. **激活空手而归**（修死分支）：移除派遣时的状态分拦截，允许低状态派遣任意档位；结算时按派遣快照判定——状态分 <20 且时长 ≥2h → 空手而归（0 瓜子、干净 −30），20–39 → 系数 0.8，与文档 1.3/1.6 一致。短档（10m/30m）不受空手判定影响。
4. **切后台折算**：visibilitychange 转隐藏时记录时间戳，回前台按离线规则折算（0.8 系数、单次上限 10h），替代现在"切后台全额衰减"。
5. **顺手修**（v003 reviewer 留档 P2 中挑三件）：stale-drag 守卫改为 `drag && e.pointerId === drag.pointerId → cancelDrag`（替换死代码守卫）；笔键过滤改 `e.button !== 0`（不再限定 mouse）；normalizeRoom 对越界 x/y 夹紧到合法摆放区间（消除"看不见但占容量"）。
6. **存档 v3**：`expedition` 单对象 → `{ slots: [slot|null, slot|null] }`；新增 `photos: { owned: [], dupSeeds: 0 }`；迁移 v2→v3 旧单槽进 slots[0]，幂等。

**不做**（留后续）：照片正式素材与高清冲洗、材料合成、探险中途加速广告位（AD06）、签到任务、皮肤。

## 4. 验收标准

1. Lv2 可派短槽（Lv1 探险入口置灰提示「Lv2 解锁探险」）；Lv4 后长槽出现；两槽同时倒计时、分别领取，刷新持久；
2. 结算按率掉照片，图鉴页收录点亮，重复卡 toast「收到重复照片，折算 +20 瓜子」且瓜子到账；
3. 状态分 <20 派 8h → 结算「空手而归」文案 + 干净 −30 + 0 收益；状态分 20–39 → 系数 0.8 生效；
4. 切后台 5 分钟回前台：衰减量 ≈ 5/60 × 0.8 × 各项每小时衰减率（DEV 关闭时验证）；
5. v2 旧档（含单槽进行中探险）升级后槽位照旧倒计时，photos 为空结构；
6. 越界坐标的存档载入后家具被夹紧到可点可收；笔侧键点商店卡片不购买；触屏 stale-drag 后新触摸可正常接管；
7. DEV 加速、存/读/重置不受影响；
8. 结算领取后鼠鼠从左侧走入房间（走行动画复用现有 walk）。
