## 2.1 四项数值

按小时衰减，离线按 0.8 系数折算，离线最多累计 10 小时（防止三天不回直接全空）。

| 数值 | 上限  | 初始 | 衰减/小时 | 满值到零    | 主要产出            | 次要产出       |
| -- | --- | -- | ----- | ------- | --------------- | ---------- |
| 饱食 | 100 | 80 | 5     | 20 小时   | 喂食 +25          | 探险回来 +10   |
| 口渴 | 100 | 80 | 7     | 14.3 小时 | 喝水 +30          | 吃水果家具 +15  |
| 干净 | 100 | 90 | 3.5   | 28.6 小时 | 洗澡 +40          | 晴天开窗 +8/小时 |
| 开心 | 100 | 70 | 3     | 33.3 小时 | 抚摸 +12 / 玩具 +20 | 摆新家具 +5    |

补充规则：

- 开心额外衰减：其余三项中每有一项 <30，开心额外 -1.5/小时（最多 -4.5/小时）。
- 状态分 = 四项加权平均（饱食 0.3 / 口渴 0.25 / 干净 0.2 / 开心 0.25），仅用于探险系数与 UI 表情，不单独展示。
- 原型的"按帧衰减"必须删除，改为记录 `lastTickAt` 时间戳，进入游戏时一次性结算。

按此设定，一天不回访，饱食剩 40 左右、口渴接近 0，鼠鼠呈现"蔫"但不死亡；两次回访即可拉满。这个强度是"提醒"而不是"逼迫"。

## 2.2 经济产出与消耗

| 项目        | 数值                   | 说明                                    |
| --------- | -------------------- | ------------------------------------- |
| 每日自然产出    | 约 480 瓜子             | 探险 2 次（45+200）+ 日常任务 150 + 签到 40 + 零散 |
| 家具价格 · 小件 | 200–500              | 首周可买 2–3 件，保证"第一天就能改变屋子"              |
| 家具价格 · 中件 | 600–1200             | 2–3 天一件                               |
| 家具价格 · 大件 | 1500–3000            | 一周一件                                  |
| 毛色服饰      | 800–1500             | 活动款不售卖，只做限定                           |
| 房间扩建      | 5000 / 12000 / 25000 | Lv8 / Lv15 / Lv22                     |
| 30 件家具总价  | 约 25000 瓜子           | 约 50 天收集完（不含活动款）                      |

货币只有一种：**瓜子**。材料（布片、木料、亮片）不作为货币，只作为 3 件手作家具的合成素材，避免双货币带来的汇率复杂度。原型里的四项数值不参与交易。

## 2.3 广告兑换汇率

**定价锚点：一次激励视频 ≈ 日均自然产出的 10%–12%，即 50 瓜子。**

| 指标          | 数值                  | 结论                  |
| ----------- | ------------------- | ------------------- |
| 单次激励视频等价收益  | 50 瓜子（含状态类、抽奖类的折算值） | 约为日均产出的 10%         |
| 每日广告次数上限    | 8 次                 | 广告日收益上限 400 瓜子      |
| 广告收益 / 自然产出 | 0.83 倍              | 不超过 1 倍，保证"不看广告也能玩" |
| 首日广告上限      | 2 次                 | 教程期不消耗信任            |

防破坏经济平衡的四条硬规则：

1. **广告只产"通用资源"，不产"稀缺资源"**——稀有材料、限定家具、活动皮肤永不出现在广告奖励里。
2. **广告只加速，不越级**——广告买不到等级、买不到扩建、买不到图鉴条目。
3. **单日上限硬编码在配置里**，服务端无（个人主体无后端），客户端 + 平台频控双保险。
4. **每周新增 1–2 件家具作为消耗口**，维持货币 sink；监控瓜子存量 P90，若周增长 >30% 则上调新家具价格或下调广告兑换。

## 2.4 JSON 配置字段清单

配置文件建议拆为 `stats.json` / `actions.json` / `expedition.json` / `economy.json` / `ads.json` / `level.json` / `events.json`，统一由 `ConfigService` 加载并做 schema 校验（字段缺失即启动报错，不允许静默降级）。

| 模块         | 字段                                                                                                        | 类型              | 说明     |
| ---------- | --------------------------------------------------------------------------------------------------------- | --------------- | ------ |
| stats      | `id` / `max` / `initial` / `decayPerHour` / `offlineFactor` / `offlineCapHours` / `lowThreshold` / `icon` | string / number | 四项数值定义 |
| actions    | `id` / `stat` / `value` / `cooldownSec` / `dailyLimit` / `exp` / `unlockLevel`                            | string / number | 照料动作   |
| expedition | `id` / `durationSec` / `slot` / `seedBase` / `materialRate` / `photoRate` / `unlockLevel` / `failText`    | string / number | 探险档位   |
| economy    | `seedPerAd` / `furniture[]`（`id`/`name`/`price`/`tier`/`happyBonus`/`atlas`） / `skins[]` / `expand[]`     | —               | 商店与定价  |
| ads        | `id` / `placement` / `trigger` / `reward` / `dailyCap` / `cooldownSec` / `minSessionSec`                  | string / number | 广告点位   |
| level      | `expBase` / `expStep` / `maxLevel` / `titles[]`（`level`/`name`）                                           | number / array  | 等级与称号  |
| events     | `id` / `startAt` / `endAt` / `rewards[]` / `assetBundle`                                                  | string / array  | 限时活动   |
