# 家具与商店 · 测试版细化设计（test-v003）

> 本文件是 test-v003（经济消耗端最小闭环）的实现依据，对应主文档模块索引 01/02。验证目标：**收集环成立**——瓜子有去处、房间肉眼可变、摆放有基本手感。验证通过后结论回写状态表，本文件随之归档为已验证设计。

## 1. 范围

**做**：

1. 商店面板：底部按钮栏新增「商店」按钮，点开底部上滑面板，列表展示可购家具（占位图、名称、价格、已购标记）；瓜子不足置灰；购买扣瓜子入库存。
2. 首批 8 件小件家具（占位像素风，代码绘制：色块 + 深色描边，配色与房间素材同一色系），价格按主文档 2.2 小件带 200–500 梯度排布。
3. 摆放：**拖拽为主**——从商店/库存面板按住家具拖出，半透明幽灵件跟随指针（绿/红提示落点合法性），拖到场景合法位置松手落定；松手在非法位置或面板区域内则取消、不消耗。移动与收回同理：按住已摆放家具直接拖到新位置；拖到底部出现的「收回」投放区松手即回库存。触屏与鼠标统一走 pointer 事件。
4. 数值挂钩：**每件家具首次摆放**开心 +5（对应 1.2 动作表「摆家具」），飘字 + 星星特效；重复摆放不再给。
5. 存档 v2：新增 `room` 结构；迁移链 v1→v2（旧档补空 room，其余进度不丢）。

**不做**（留给后续迭代）：中件/大件、房间扩建、家具图鉴页、家具数探险加成（2%）、朝向旋转、皮肤、材料合成、商店分页。

## 3. 交互细节（横屏 640×360）

- **入口**：底部按钮栏在「探险」左侧插入「商店」，按钮总数 7（照料 5 + 商店 + 探险），图标宽度相应收窄；探险倒计时中商店仍可用。
- **拖拽**：pointerdown 在商店/库存条目或已摆放家具上 → pointermove 幽灵件跟随（绿/红合法性提示）→ pointerup 落定或取消；拖拽已摆放家具时底部浮现「收回」投放区；探险倒计时中商店可用，摆放不受探险状态限制（房间布置随时可做）。
- **碰撞**：AABB 简单相交判定，参照 scene.js 现有物件命中框；不做出重叠时的精细避让。
- **容量上限**：同屏已摆放上限 12 件（含初始 5 固定物件之外的摆件），超出提示「房间放不下了」——为将来扩建留价值感。
- **层序**：贴墙件（挂画、秋千）绘制在鼠鼠之后；地面件绘制在鼠鼠之前（与现有物件同层，按 y 排序）。

## 5. 验收标准

1. 攒够瓜子买 2 件 → 从面板拖拽放置进房间 → 刷新页面，家具原位保留；
2. 拖拽移动一件、拖到「收回」区收回一件，重载后状态正确；
3. 首次摆放瞬间开心 +5、有飘字与特效；同一件（含收回重摆）不再给；
4. 瓜子不足时购买被拒并有 toast；非法落点点不下；
5. v1 旧档升级：数值/瓜子/探险进度全保留，room 为空；
6. DEV 调试加速、存/读/重置不受影响；
7. 收齐 8 件的时间体感不空转（以 DEV 加速模拟三日验证）。
