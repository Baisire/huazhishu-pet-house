# 测试版

纯 HTML/JS 的可玩测试版，用来验证玩法、手感、数值节奏。**这里不是自动化测试目录**，不需要 test runner。

## 定位

- 只服务于"验证决策"，不追求代码质量与包体指标。
- 验证通过的效果，才按 `release/` 的准入条件转成正式版。
- 允许快速试错、推倒重来，但要遵守 tag 轮转规则，避免版本堆积。

## 分层

与设计文档 4.2 保持一致，后续迁移正式工程时可以直接对应：

| 目录 | 职责 |
| --- | --- |
| `src/platform/` | 平台差异封装：抖音 / H5 / 模拟广告 |
| `src/data/` | 存档读写、迁移、配置加载 |
| `src/core/` | 纯逻辑：数值结算、探险、经济、成就 |
| `src/view/` | 场景与角色绘制、动画、特效 |
| `src/ui/` | 面板、按钮、数值条、Toast |
| `src/config/` | JSON 配置：数值、广告点位、称号 |
| `assets/` | 图片与音频 |

## 运行

直接双击 `index.html`，或在本目录起静态服务（涉及跨文件 fetch 配置时必须用服务方式）：

```bash
npx serve test
```

## 版本

- 每个可玩节点打 `test-vNNN` tag，只保留最近 3 个：`tools/rotate-test-tags.ps1`。
- 详细规则见仓库根目录 [README.md](../README.md)。
