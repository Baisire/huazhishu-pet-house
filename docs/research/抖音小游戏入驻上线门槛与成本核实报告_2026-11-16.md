# 抖音小游戏入驻与上线：门槛、真实成本、时间线核实报告

- 核实日期：2026-11-16
- 核实对象：抖音开放平台「小游戏」（含直播小玩法差异单独标注）
- 证据基准：当日可访问的抖音开放平台官方文档、政府/司法机关公开文件、官方政务服务平台报价页
- 使用提醒：平台政策随时更新，本报告标注了每份文档的页面更新时间。**落地前请在开发者后台复核一遍**，尤其是涉及"是否需要版号""ICP 备案入口是否开放"这两项。

## 0. 结论速览（可以直接拍板的部分）

| # | 结论 | 证据等级 |
|---|---|---|
| 1 | **个人可以不做公司，直接做纯广告变现（IAA）的抖音小游戏**：个人主体可创建小游戏（文档写 50 个），个人主体有独立的 ICP 备案流程，广告结算规则单列"个人开发者"的计税方式 | 官方文档（高） |
| 2 | **内购（IAP）个人做不了**：版号是开通内购的必要凭证；虚拟支付开通还要求完成企业主体认证 | 官方文档 + 官方社区答复（高） |

| 6 | **最快 1.5–2.5 个月、稳妥 4–5 个月**（不含开发工期），差异几乎全部来自软著是"加急"还是"普通 60 日" | 官方时效 + 推算（中） |

**一句话决策**：如果你的目标是"用最低成本验证一款 IAA 小游戏能不能跑起来"，正确路径是**个人主体 + 软著加急 + 纯广告变现**，首年现金支出可以压到 1,000 元以内（不含开发）；注册公司应该放在"验证成功之后"，否则注销成本会高于验证成本。

## 1. 核实方法与证据等级说明

本报告所有数字都标注来源，并按以下等级区分：

- **【官方·强制】**：抖音开放平台文档、法规原文、政府公告中明确写出的要求或时效。
- **【官方·报价】**：政府背景服务平台（如上海市企业服务云、浙江省企业之家网）公示的服务价格，属于"可查报价"，不等于全国统一价。
- **【市场价】**：代办/服务机构公开报价，只代表区间，不是规定。
- **【经验判断】**：无官方口径，按行业普遍情况给出，**不可当作政策依据**。
- **【未能核实】**：查不到可靠出处，明确留空，不做估算填空。

需要特别说明的两处官方口径不一致：

1. 抖音开放平台**通用入驻文档**写"个人主体仅支持创建小玩法，小程序/移动应用/网站应用仅支持企业主体"；而**小游戏专项入驻文档**写"个人开发者：个人主体验证适用于由个人运营的小游戏，每个个人主体可以创建 50 个小游戏"，主体类型表也写"个人：仅可创建小玩法和小游戏"。本报告以**小游戏专项文档**为准，但请以后台实际开放的应用类型为最终依据；若后台只给"小玩法"入口，需提工单确认。
2. 信用分体系已于 2026-01-15 下线，原"信用分≥60"类准入条件改由"小游戏主体评级体系"承接。凡引用旧信用分门槛的说法都已过期。

## 2. 主体资质：个人 / 个体工商户 / 企业

### 2.1 三类主体对照

| 维度 | 个人开发者 | 个体工商户 | 企业（有限公司等） |
|---|---|---|---|
| 是否可入驻 | 可以 | 可以（归入"企业身份"大类） | 可以 |
| 可创建小游戏数量 | 50 个 | 100 个 | 100 个 |
| 需要营业执照 | 不需要 | 需要 | 需要 |
| 需要对公账户 | 不需要（用本人实名银行卡） | **需要**（官方：对公验证、流量主环节需使用） | 需要 |
| 主体认证审核时效 | 约 1 个工作日 | 约 3 个工作日 | 约 3 个工作日 |
| 对公验证 | 银行账户实名认证（本人银行卡） | 法人人脸/银行账户/平台打款/客户打款，四选一 | 同左 |
| 纯广告变现（IAA） | 可以 | 可以 | 可以 |
| 内购（IAP） | 不可以（无版号 + 虚拟支付需企业主体） | 理论可，实际受版号制约 | 可以，需版号 |
| 港澳台/海外主体 | 不支持 | 不支持 | 不支持（官方：会导致小游戏无法上线） |
| 入驻/认证费用 | 文档未列收费项 | 企业认证明确免费 | 企业认证明确免费 |

依据：
- 主体类型、数量上限、审核时效、对公验证四种方式、个体工商户必须有对公账户、港澳台海外不支持：抖音开放平台《注册与入驻》（页面更新 2024-03-11）。
- 企业认证免费：抖音开放平台《开发者入驻常见问题》Q5。
- 个人结算与计税：抖音开放平台《小游戏广告收入结算规则》"如果开发者为个人开发者，开发者收益 = 可分配收益/(1+6%) − 个人所得税"。
- 虚拟支付需企业主体：抖音开放平台开发者社区官方答复"小游戏开通虚拟支付必须完成企业主体认证才能申请"。

### 2.2 营业执照经营范围有要求吗？

- **平台侧没有规定必须写某个经营范围**：开放平台入驻文档只要求营业执照信息与国家企业信用信息系统一致，未对经营范围做强制限定。
- **但 ICP 备案有"命中即触发"规则**：营业执照名称或经营范围若命中"出版、教育、医疗保健、药品和医疗器械、文化、广播电影电视节目、新闻、网络预约车、互联网金融、校外培训（高中及以下）、宗教"任一项，即使实际不做，也要在备案时提交"不从事相关内容承诺书"或在备注中说明，否则会被驳回。
- 实务含义：经营范围写"技术服务、软件开发、动漫游戏开发"这类即可，**主动避开"出版""文化"字样**能少一轮补正（此为经验判断，非官方要求）。

### 2.3 这条为什么改变决策

个人主体的固定成本结构是"零主体成本"：

- 不需要营业执照、不需要刻章、不需要对公账户、不需要代理记账、不需要年报；
- 收入由平台按"个人开发者"公式代扣个人所得税后打款；
- 唯一的硬支出是软著（官费 0，代办加急几百到几千）。

对比之下，注册公司会立刻引入：刻章、开户、每月代账、每季度报税、每年年报，以及**失败后的注销成本**。所以"先用个人主体验证，跑通再注册公司"是成本最优顺序。

## 3. 游戏类目资质：上线到底需要哪些材料

### 3.1 一张表看清

| 材料 | 是否必需 | 关键要求 | 依据 |
|---|---|---|---|
| 计算机软件著作权登记证书（软著） | **必需**（提审必传，备案必用） | 游戏名与软著软件名完全一致；著作权人与平台主体完全一致（不一致需授权书）；同一软著只能一款小游戏在线；电子软著可用于准入但**不能用于小游戏备案** | 《小游戏资质规范》《审核常见问题-资质篇》 |
| 自审自查报告 | 必需，但**不用上传文件** | 2024-07-11 起改为后台勾选确认；内容按《小游戏自审自查事项》自查（含未成年人保护、防沉迷、适龄提示等） | 《小游戏资质规范》 |
| 广电总局版号（ISBN） | **仅内购必需**；纯 IAA 不强制 | 名称需与平台名称完全一致；运营单位需与主体一致；游戏类型须为移动端 | 《审核常见问题-资质篇》 |
| 小游戏备案（市宣备案） | **所有小游戏必需** | 有版号者无需重复备案；平台在"基础信息 + 版本"双通过后自动申报 | 《小游戏备案申报》 |
| ICP 备案 | **所有小游戏必需** | 有版号：入口自动开启；无版号：必须先完成小游戏备案才开入口 | 《ICP 备案指引》 |
| 商标 / IP 授权 | 视内容 | 使用第三方商标、动漫形象、音乐等需"作品登记证书/商标注册证 + 完整授权链" | 《审核常见问题-资质篇》 |
| 其他合规 | 必需 | 适龄提示、未成年人防沉迷、实名认证（中宣部系统）、隐私政策；棋牌类仅开放"棋类" | 《小游戏自审自查事项》《基础信息审核规范》 |

### 3.2 版号：把"免不免"说清楚

- **纯广告变现（IAA）不需要版号**，走"小游戏备案 → ICP 备案"。官方 ICP 文档原文逻辑是：无版号的小游戏先完成小游戏备案，ICP 备案入口才开放，且前置审批信息由平台自动同步备案材料。
- **内购必须有版号**。官方原文："【广电总局版号批文】，即通常所说的【版号】，是小游戏开通内购能力的重要凭证"；平台发布文档也写"开通内购能力…资质提交完全，例如版号必须提交"。
- **无版号时不要做任何内购设计**。官方明确"无版号时请勿在扩展组件内设计中心化的'商城'及类似功能（包括代币购买形式，如积分、金币等）"。

### 3.3 备案的两段式流程（最容易误判工期的地方）

1. **小游戏备案（市宣）**：基础信息审核通过 + 版本提审通过后，平台自动申报；市宣审核官方预估 **10–15 个工作日**；平台不保证具体时效。
2. **ICP 备案**：平台审核 **1–3 个工作日** → 工信部短信核验（收到后 **24 小时内**完成）→ 管局审核 **1–20 个工作日**（各省不同，不能催审）。

两者是**串行**关系，不是并行。很多人把"10–15 个工作日"当成总备案时长，实际还要再加管局这一段。

## 5. 时间线：一条最快路径、一条稳妥路径

### 5.1 各环节官方时效（这张表是推算基础）

| 企业主体认证 | 约 3 个工作日 | 官方 | 《注册与入驻》 |
| 对公验证 | 实时 – 2 个工作日 | 官方 | 《注册与入驻》 |

### 5.2 串行 / 并行关系

**硬串行（不能跳）**：
定游戏名 → 申请软著（名称必须一致）→ 填写基础信息 + 提审版本 → 小游戏备案（市宣）→ ICP 备案（平台审 + 管局审）→ 发布上线 → 15 天内申请冷启流量。

**可并行**：
- 注册主体 与 申请软著（互不依赖）；
- 游戏开发 与 软著申请（代码定稿即可申请，不必等上线）；
- 刻章/开户/签约代账 与 软著等待期；
- ICP 短信核验与管局审核之间只有 24 小时窗口，必须盯人。

**不能并行的关键点**：小游戏备案与 ICP 备案是串行；无版号时 ICP 入口要等备案通过才开。

### 5.3 最快路径（个人主体 + 软著加急 + 一次过审）

| 阶段 | 耗时（工作日） |
|---|---|
| 软著加急（5 个工作日档） | 5 |
| 个人主体认证 | 1 |
| 基础信息 + 版本审核 | 约 3–5 |
| 小游戏备案（市宣） | 10–15 |
| ICP（平台 1–3 + 管局 7–20） | 8–23 |
| **合计** | **约 27–49 个工作日（约 1.3–2.3 个月）** |

现实约束：软著 5 个工作日档报价最高（约 4,000 元），且需要材料一次过；管局实际时长不可控。**建议对外按 2.5 个月排期。**

### 5.4 稳妥路径（企业主体 + 普通软著 + 留补正余量）

| 阶段 | 耗时 |
|---|---|
| 注册公司 + 刻章 + 开户 | 5–15 个工作日（市场经验，未核实官方统一时限） |
| 企业主体认证 + 对公验证 | 3–5 个工作日 |
| 软著普通申请 | 60 日（自然日，约 2 个月） |
| 基础信息 + 版本审核 | 4–6 个工作日（含补正） |
| 小游戏备案（市宣） | 10–15 个工作日 |
| ICP（平台 + 管局） | 10–23 个工作日 |
| **合计** | **约 4–5 个月** |

### 5.5 三个会毁掉时间表的坑

1. **先开发后定名**：软著名称与游戏名必须完全一致，上线后改名每年只有 2 次，且改软著/版号名称会触发"重新做小游戏备案 + ICP 备案"。**名字必须在写软著前定死。**
2. **一份软著想上两款游戏**：官方明确"同一软著仅支持一款小游戏在线运营"。
3. **用电子软著去备案**：电子软著可过平台资质准入，但**不能用于小游戏备案**，必须拿国家版权局证书。

### 6.2 官方给的免费流量：新游冷启计划（唯一可量化承诺）

- 对象：2023-07-25 之后首次上线的小游戏。
- 阶段一：首次上线 **15 天内**申请，申请后 **3 天内**获得 **1 万**小游戏中心专属曝光。
- 阶段二：平台按日评级，自动追加 **0–10 万**曝光，无需申请。
- 阶段三：首次发布 **180 天内**、评级达标可申请，最高 **60 万**曝光。
- 限制：每款游戏只能拿一次；评级结果不透传；**平台明确"无法对转化用户量做出保证"**。

注意：该文档更新时间为 2023-09-06，2026 年是否原样执行**未能核实**，需以后台"新游冷启计划"页面为准。

### 6.3 达人分发：发行人计划 / 小程序推广计划

- 机制：开发者发布推广任务 → 达人接单拍视频/直播 → 视频自带小游戏锚点 → 按 CPA/CPA+CPS 结算。
- 成本口径：CPS 买量消耗 =（该游戏带来的开发者税前收益 − 历史欠款）× CPS 分成比 ×（1 + 星图服务费 3%）。
- 这是"不投信息流广告但付费"的中间路线：付的是达人佣金，不是平台广告费。

### 6.4 变现分成（决定单位流量值多少钱）

| 场景 | 开发者现金分成 |
|---|---|
| 广告收入·非投广（自然量） | **60%** |
| 广告收入·投广（买量） | **90%** |
| 内购·一般版 | 内购结算基数 **60%** |
| 内购·减免版·非投广 | **80%** |
| 内购·减免版·投广 | **90%** |

- 结算：半月结，累计不足 **1,000 元**可暂不结算（年末不足 1,000 元时年底结清）；企业需在 15 个工作日内寄增值税专用发票。
- 个人开发者：收益 = 可分配收益/(1+6%) − 个人所得税。

### 6.5 不买量到底能拿多少自然量

**官方口径：没有。** 平台只承诺"曝光量级"，不承诺转化，也没有公布自然量占比。

**经验判断（非官方，不可作为决策依据）**：
- 冷启的 1 万曝光是"曝光"不是"用户"，按行业常见的小游戏中心点击率与进入率，实际带来的新增用户通常在数百到数千量级，且高度依赖 icon、名称、首屏体验；
- 冷启结束后，如果没有短视频/直播内容持续供给，自然量会在数周内快速衰减；
- 抖音小游戏的流量结构本质是"内容驱动"，不是"商店驱动"——没有达人内容和投放，纯自然量的天花板很低。

以上三条均为行业经验，**没有官方数据支撑，报告中不作为承诺**。

## 7. 注销与退出：项目失败时怎么收场

### 7.1 两种注销路径（《企业注销指引（2025 年修订）》，市场监管总局等六部门 2025 年第 52 号公告）

| 维度 | 简易注销 | 一般注销 |
|---|---|---|
| 适用条件 | 未发生债权债务或已清偿完结，未发生/已结清费用、工资、社保、税款，全体投资人书面承诺 | 不满足简易条件，或存在债权债务、异常状态 |
| 公示/公告 | 公示期 **20 日** | 清算组自成立之日起 10 日内通知债权人，**60 日内**发布债权人公告；债权人 45 日内申报 |
| 办理窗口 | 公示期满起 **20 日内**申请（可延长，最长不超过 30 日，即最晚 50 日内） | 清算完成后申请 |
| 是否需清算组 | 不需要 | 需要（解散事由出现之日起 15 日内成立） |
| 税务 | 未办过涉税事宜、或未领发票且无欠税罚款的，**免予单独办清税证明** | 需办理税务注销（符合容缺条件可即时出清税文书） |
| 实际耗时 | 约 1–2 个月（市场经验） | 约 3–6 个月（市场经验） |
| 费用 | 自办 0 元；代办约 1,000–4,000 元 | 自办 0 元；代办约 4,000–10,000 元以上 |

个体工商户同样可以走简易注销，且没有清算组和股东会决议这类负担，退出成本低于有限公司。

### 7.2 不注销、长期零申报的风险（这部分是硬后果）

| 行为 | 后果 | 依据 |
|---|---|---|
| 逾期未申报 | 责令限期改正，可处 **2,000 元以下**罚款；情节严重处 **2,000–10,000 元** | 《税收征管法》第六十二条（税务总局 12366 答复） |
| 长期零申报/失联被认定非正常户 | 罚款（华东区域裁量基准：单位 500 元起，欠税不满 20 万的可处 1,000–2,000 元） | 华东区域税务行政处罚裁量基准 |
| 未按期公示年报 | 列入**经营异常名录**，可依法行政处罚 | 《企业信息公示暂行条例》第十八条 |
| 连续 2 年未年报且登记住所无法联系 | **吊销营业执照** | 《企业信息公示暂行条例》第十八条 |
| 成立后无正当理由超 6 个月未开业 / 开业后停业连续 6 个月以上 | 登记机关**可以吊销营业执照**（依法歇业除外） | 《公司法》第二百六十条 |

要点：**"吊销"不等于"注销"**。被吊销后主体仍然存在，仍需清算注销，且法定代表人/负责人会在信用、任职、出行等方面受限。拖着不处理的成本，通常高于花几千元注销。

## 8. 决策建议（按你的实际情况选一条）

### 方案 A：个人主体 + 纯 IAA（推荐用于验证阶段）

- 现金投入：软著 0–4,000 元 + 平台 0 元 + 主体 0 元 ≈ **1,000 元级别**。
- 时间：约 **1.5–2.5 个月**（软著加急前提下）。
- 上限：不能内购、分成按 60%（自然量）、收益扣个税、单主体 50 款。
- 适合：先验证玩法与留存，用广告变现跑正单位经济模型。

### 方案 B：个体工商户 + IAA（中间态）

- 需要营业执照 + 对公账户 + 代账，年固定成本约 **2,400–4,800 元**。
- 好处：可以走对公结算、以主体身份接发行/合作、注销比公司简单。
- 适合：已经确认要长期做，但还不需要内购和融资主体。

### 方案 C：有限公司 + IAA/IAP（长期做）

- 首年成本约 **2,400–12,000 元**，年维持 **2,400–4,800 元**，注销 **0–10,000 元**。
- 前提：要有版号才能内购（版号本身周期与成本不在本报告范围，需单独立项核实）。
- 适合：确定做内购、要接发行、要签合同开专票。

### 明确不建议的做法

**先注册公司再验证玩法。** 验证失败时，注销的时间（1–6 个月）和钱（0–10,000 元）会超过验证本身的成本；而个人主体路径已经能完整跑通"上线—广告变现—结算"。

## 9. 明确"未能核实"的清单

以下项目本次查不到可靠官方出处，不做数字填充：

1. **基础信息/资质审核的具体时效**——平台文档未公示，仅能参考版本审核 1–2 个工作日。
2. **小游戏中心自然量的官方占比或均值**——平台无公开口径。
3. **新游冷启计划在 2026 年是否仍按 2023 年文档执行**——文档停留在 2023-09-06。
4. **各地刻章、银行开户的实际收费**——地区差异极大，且 2026 年多地取消免费刻章，需按注册地核实。
5. **管局审核的实际天数**——官方只给 1–20 个工作日区间，无法预测。
6. **平台是否存在文档外的隐性收费**——文档未列，只能以后台账单为准。
7. **版号申请的时间与费用**——不属于平台流程，需另行核实（本报告只确认"内购必须有版号"）。
8. **个人主体在"广告中心-流量主"的实际前置校验**——官方表述为"完成主体资质认证和对公验证后"可对已上架小游戏申请；个人主体对应的是"银行账户实名验证"，但后台申请页是否另要求对公账户，未能核实，需以申请页提示为准。
