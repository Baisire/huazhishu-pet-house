## 3.1 画风定位

**"纸片黏土小屋"**：2.5D 侧 45° 俯视的小屋，背景是手绘水彩纸质感，家具是带 1–2px 深色描边的扁平色块 + 顶部高光，鼠鼠是厚涂小方脸的 Q 版纸片角色。

与旅行青蛙的差异点（必须明确，否则会被判定为换皮）：

| 维度   | 旅行青蛙  | 本作                            |
| ---- | ----- | ----------------------------- |
| 视角   | 平视 2D | 侧 45° 俯视的立体小屋                 |
| 核心资产 | 明信片   | 可摆放、可扩建的房间                    |
| 角色行为 | 出门/回家 | 屋内 6 种持续行为（进食/喝水/理毛/睡觉/跑轮/发呆） |
| 情绪表达 | 文字叙述  | 角色表情 + 待机动作                   |
| 美术质感 | 木版画   | 水彩纸 + 纸片分层                    |

## 3.3 角色比例与骨骼拆分

- 头身比 **1 : 1.25**，头部占全高 52%，身体短圆，四肢各 2 节。
- 建议画布 192×192（在 750 宽设计稿上显示约 110px 高），朝右为基准朝向，朝左整体镜像。

骨骼/图层拆分（帧动画方案下的图层顺序，从后到前）：

```
tail_03 → tail_02 → tail_01 → leg_L_back → arm_L_back → body
→ leg_R_front → arm_R_front → head → ear_L → ear_R → face(眼/鼻/嘴)
```

关键约束（直接对应原型问题 3、4）：

- 尾巴 3 段，跟随身体摆动做 2 帧延迟，方向永远背离身体朝向；
- 耳朵挂在 head 节点下，不做独立世界坐标定位；
- 面部（眼鼻嘴）单独一层，用于表情切换，不重绘整个头。

## 3.4 动画原则

| 项    | 规范                                 |
| ---- | ---------------------------------- |
| 帧率   | 12 fps（像素/纸片风统一手感），UI 补间 30/60 fps |
| 待机   | 呼吸循环 2 秒，胸腔起伏 3%，5 秒插一次耳朵抖动        |
| 挤压拉伸 | 落地/跳跃 squash 8%，不做夸张变形             |
| 尾巴延迟 | 3 段依次延迟 2 帧（跟随动作）                  |
| 动作时长 | 单动作 6–12 帧；进食 8 帧循环，理毛 10 帧循环      |
| 转场   | 场景切换 0.3 秒淡入，不使用花哨转场               |

动作清单（共 14 个，每个动作一套图层序列）：idle、eat、drink、groom、sleep、run\_wheel、daze、happy、sad、dirty、pet、explore\_out、explore\_back、carry（叼东西）。

## 3.5 UI 规范

- 设计分辨率 **750×1334**，适配安全区（顶部预留 120px，底部预留 100px）。
- 圆角 12px，描边 2px（深木色），投影 0 4px 12px rgba(90,58,36,0.18)。
- 字号 24 / 28 / 36 / 48；正文行高 1.5。
- 最小点击热区 **88×88**，按钮间距 ≥ 16。
- 底部动作栏高 140，最多 5 个主按钮；四项数值常驻顶部左上，采用"图标 + 细条"，不显示数字（数字在详情面板里）。
- 所有面板从底部上滑，240ms，ease-out。

## 3.7 AI 出图工作流

AI 只用于**概念与色彩探索**，不直接进包。流程：

1. 用"水彩纸质感 + 纸片分层 + 暖木色 + 1px 深棕描边 + 侧 45 度俯视"作为固定 prompt 前缀，一次出 8 张概念；
2. 选定方向后人工描线重绘为等距场景，统一光源（左上 45°）；
3. 角色必须由同一套模板绘制，禁止不同动作来自不同批次；
4. 所有出图需去底、裁边、对齐锚点（脚底中心），再打包图集；
5. AI 生成物保留 prompt 与修改记录，用于软著说明书中的"美术设计说明"。
