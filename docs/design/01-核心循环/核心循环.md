## 1.1 三层结构

```
        ┌──────────── 日常陪伴层（每天 2–4 次，单次 3–5 分钟）────────────┐
        │  喂食 / 喝水 / 洗澡 / 抚摸 / 摆家具 → 四项数值回升、亲密度+EXP   │
        └───────────────┬──────────────────────────────▲─────────────────┘
                        │ 数值达标解锁派遣              │ 战利品摆进屋子
                        ▼                              │
        ┌──────────── 探险层（挂机计时，回来结算）───────┴─────────────────┐
        │  10 分钟 / 30 分钟 / 2 小时 / 8 小时 → 瓜子 + 材料 + 照片卡       │
        └───────────────┬──────────────────────────────▲─────────────────┘
                        │ 产出货币                      │ 消耗货币
                        ▼                              │
        ┌──────────── 收集层（长期目标）────────────────┴─────────────────┐
        │  30 件家具 / 8 套毛色服饰 / 40 张照片图鉴 / 20 个称号 / 3 次扩建 │
        └─────────────────────────────────────────────────────────────────┘
```

三层的关系是**时间尺度的嵌套**：陪伴层以分钟计，探险层以小时计，收集层以天/周计。任何一层单独存在都不成立——只有陪伴没有探险，房子是静态的；只有探险没有收集，收益没有去处；只有收集没有陪伴，鼠鼠就成了纯数值容器。

## 1.2 日常陪伴层

| 动作  | 效果        | 冷却    | 消耗             | 亲密度 EXP       |
| --- | --------- | ----- | -------------- | ------------- |
| 喂食  | 饱食 +25    | 10 分钟 | 免费（每日 6 次后需等待） | +5            |
| 喝水  | 口渴 +30    | 8 分钟  | 免费             | +3            |
| 洗澡  | 干净 +40    | 30 分钟 | 免费             | +8            |
| 抚摸  | 开心 +12    | 60 秒  | 免费             | +2（每日上限 30 次） |
| 玩玩具 | 开心 +20    | 5 分钟  | 需拥有对应家具        | +6            |
| 摆家具 | 开心 +5 / 件 | 无     | 需在库存中          | +4            |

关键约束：**动作本身不消耗货币**。免费动作保证"穷也能玩"，货币只用于买家具和皮肤。这是纯 IAA 产品的必然选择——把付费墙换成广告墙，而不是把基础照料做成资源消耗。

数值低于 25 时，对应动作按钮出现呼吸光晕；低于 10 时鼠鼠切换到"蔫"的待机动作（不含任何惩罚数值）。

## 1.3 探险层

- **槽位**：2 个。短槽（10 分钟 / 30 分钟 / 2 小时），长槽（2 小时 / 8 小时）。Lv2 解锁短槽，Lv4 解锁长槽。
- **派遣条件**：状态分 ≥ 20 才能派 2 小时以上；鼠鼠出门期间不能互动（这是天然的时间门槛，不需要额外"体力"系统）。
- **收益公式**：

```
瓜子收益 = 基础值 × 状态系数 × (1 + 0.02 × 已解锁家具数) × 广告倍率
状态系数：状态分 ≥70 → 1.1；40–69 → 1.0；20–39 → 0.8；<20 → 0.6
```

| 时长    | 基础瓜子 | 材料掉落率    | 照片卡概率 | 备注            |
| ----- | ---- | -------- | ----- | ------------- |
| 10 分钟 | 20   | 10%      | 15%   | 高频短反馈，教学期主力   |
| 30 分钟 | 45   | 15%      | 25%   | 日常主力          |
| 2 小时  | 90   | 20%      | 40%   | 上班/上课场景       |
| 8 小时  | 200  | 35%（含稀有） | 60%   | 过夜，稀有材料唯一稳定来源 |

- **失败处理**：探险不存在"失败"状态，只有"收获差"。状态分 <20 时派 8 小时，结算为"空手而归 + 一身泥"（收益 0，干净 -30），不扣瓜子、不掉等级、不丢家具。这是"有代价但不伤人"的中间态。
- **探险中的表现**：派遣后小屋变空（鼠鼠不在），窗台出现小脚印；返回时从门口跑进来，带一个可打开的包袱。这段表演是留存的关键情绪点，必须做足。

## 1.4 收集层

| 收集线   | 数量                         | 获取方式                           | 长期价值              |
| ----- | -------------------------- | ------------------------------ | ----------------- |
| 家具    | 30 件（小件 14 / 中件 10 / 大件 6） | 瓜子购买、探险材料合成 3 件、活动限定 2 件       | 改变小屋外观 + 少量收益加成   |
| 毛色与服饰 | 8 套（3 套初始配色沿用原型）           | 瓜子购买 5 套、活动 2 套、签到第 7 天 1 套    | 情感投射，最容易被截图分享     |
| 照片图鉴  | 40 张                       | 探险随机带回，重复可"冲洗"成高清卡             | 图鉴页是 banner 唯一挂载处 |
| 称号    | 20 个                       | 等级 + 行为成就                      | 展示在鼠鼠名牌上          |
| 房间扩建  | 3 次（小屋 → 带阳台 → 双层）         | 5000 / 12000 / 25000 瓜子 + 等级门槛 | 最大的长期目标           |

## 1.5 节奏设计

| 维度     | 目标值             | 依据                       |
| ------ | --------------- | ------------------------ |
| 单次会话时长 | 4 分钟 ± 1.5 分钟   | 收探险 + 补给 + 摆家具 + 1–2 次广告 |
| 每日回访   | 2–4 次（早、午、晚、睡前） | 与 4 组探险时长对齐              |
| 首次会话   | 6–8 分钟（含教程）     | 教程内必须完成 1 次探险并看到收益       |
| 周级解锁   | 见下表             | 一周内把三层全部打开，避免"第七天才好玩"    |

首周解锁节奏（按等级推进，不按自然日强制）：

| 天    | 等级    | 解锁               |
| ---- | ----- | ---------------- |
| Day1 | Lv1–2 | 教程、基础照料、短探险槽     |
| Day2 | Lv3   | 商店（家具）、日常任务      |
| Day3 | Lv4   | 长探险槽（2 小时）       |
| Day4 | Lv5   | 照片图鉴、分享照片卡       |
| Day5 | Lv6   | 签到 7 日链、订阅消息引导   |
| Day6 | Lv7   | 毛色第二套、手作合成       |
| Day7 | Lv8   | 房间第一次扩建（首个大目标达成） |

## 1.6 失败与惩罚机制的取舍

**明确不做**：数值归零致死、掉级、家具损坏、探险物品丢失、限时强制任务。理由有三：

1. 目标用户是治愈向轻度用户，惩罚会直接转化为卸载；
2. 纯 IAA 不靠"复活付费"变现，惩罚没有商业回报，只有流失成本；
3. 抖音小游戏的用户来源是内容推荐，负反馈会被放大到评论区。

**替代方案（已采用）**：

| 机制    | 表现                   | 恢复方式               |
| ----- | -------------------- | ------------------ |
| 状态分衰减 | 探险收益系数下降（最低 0.6）     | 做 3–4 次照料动作即回到 70+ |
| "蔫"状态 | 待机动作变慢、耳朵下垂、表情变化     | 任意数值回到 50 以上自动解除   |
| 空手而归  | 8 小时探险收益为 0，干净 -30   | 洗一次澡即恢复            |
| 断签    | 签到链回到第 1 天（不损失已领取奖励） | 可看 1 次广告补签，每日 1 次  |

这套设计的核心是：**惩罚只影响"这一轮的效率"，不影响"已有的资产"**。
