# 留存三件套 · 测试版细化设计（test-v005）

> 本文件是 test-v005（首次引导 + 日常任务 + 7 天签到）的实现依据，对应主文档模块索引 01（1.5 节奏）/ 06（6.1 签到、6.2 任务）。验证目标：**新玩家首日有明确指引不迷路，次日有回来的理由**。

## 0. 分工边界

- **玩法线（本任务全部范围）**：`core/state.js`、`data/save.js`、`config/gameConfig.js`、`ui/hud.js`、`main.js`
- **表现线（搭档，后续接入）**：引导插图/签到日历皮肤化、任务图标正式素材；教程的演出化包装
- 占位方案：提示条与面板均为现有 HUD 风格的代码绘制；签到奖励物用文字 + 瓜子图标

## 1. 范围

**做**：

1. **首次引导（完整遮罩式，用户拍板）**：新档首进入触发分步引导，共 6 步——①欢迎 + 抚摸鼠鼠（点鼠鼠）→ ②喂食 → ③派遣探险（10 分钟档）→ ④等待说明（无目标，弹层文字 + 「继续」按钮）→ ⑤领取探险 → ⑥商店介绍（买任意家具即完成）。每步：半透明遮罩罩住全屏，目标区域挖空高亮 + 气泡文字指向；**遮罩期间仅高亮目标与「跳过」按钮可点**，其余交互全部拦截（步骤 ④ 整屏遮罩仅「继续」可点）；`flags.tutorialDone` 落档，跳过即完成，重置后重新触发。
2. **日常任务 5 条**（文档 6.2 原表）：喂食 3 次(30) / 洗澡 1 次(30) / 完成 1 次探险(40) / 摆放或更换家具 1 次(25) / 看 1 次激励视频(25)；全完成额外 +100 瓜子 +20 EXP。每日重置；逐条领取 + 全勤奖单独领取。
3. **7 天签到**（文档 6.1 循环制）：30/40/50/60/80/100/第 7 天；**第 7 天奖励占位为 300 瓶子**（文档为皮肤碎片 ×3，皮肤系统未实现，状态表记偏差，皮肤落地后替换）；断签回第 1 天（不扣已领）；广告补签 1 次/日（模拟广告）。
4. **入口**：每日首次进入自动弹出「今日」面板（签到/任务两页签）；关闭后通过 HUD 顶部瓜子栏下方新增小按钮「今日」随时重开（不占底部按钮栏）。
5. **存档 v4**：`progress: { tutorialDone, checkinDay, lastCheckinDate, tasks: { day, counts: {feed,bath,exp,place,ad}, claimed: [], bonusClaimed } }`；迁移 v3→v4 补空 progress，幂等。

**不做**（留后续）：订阅消息引导、侧边栏入口、限时活动、皮肤碎片兑换、任务成就化。

## 2. 规则细节

| 项 | 值 | 依据 |
| --- | --- | --- |
| 引导触发 | 新档（无 flags.tutorialDone）且首次进入 | 文档 1.5 首次会话 |
| 引导步数 | 6 步，可跳过；跳过即 tutorialDone=true | 成本/体验折中 |
| 任务计数来源 | 复用现有 daily 计数扩展（喂食/洗澡）；探险完成在 settle 时计；摆放在 place/retrieve 后 place 计；看广告在 markAdWatched 计 | 复用 v003/v004 机制 |
| 签到判定 | 自然日（dayKey）比对 lastCheckinDate；当日已签则显示「明日再来」 | 文档 6.1 + 7.3 自然日口径 |
| 断签 | 跨天后 checkinDay 归 1；补签仅修「昨天漏签」（广告后 checkinDay +1 并落档） | 文档 6.1 |
| 签到循环 | 第 7 天领完回到第 1 天（循环制） | 文档 6.1 |
| 任务领取 | 逐条领取；全勤奖在 5 条全领后解锁；领取即存档 | 文档 6.2 |

## 3. 验收标准

1. 新档首进触发引导，按步完成 6 步后 tutorialDone 落档；跳过也落档；
2. 引导第 3 步派出的探险在领取后任务「完成 1 次探险」计数 +1；
3. 任务逐条领取数值正确、全勤奖解锁并到账；跨天重置；
4. 签到 7 天循环领取数值正确；断签回第 1 天；补签每日限 1 次且正确落档；
5. 每日首次进入自动弹「今日」面板，之后可从顶部小按钮重开；
6. v3 旧档升级全保留（房间/探险/照片/瓜子），progress 补空；重置后引导重新触发；
7. DEV 调试与 v003/v004 全部既有功能（商店/家具/拖拽/双槽/图鉴）无回归；
8. 引导遮罩期间：只有当步高亮目标与「跳过」按钮可点（其余区域点击被吞且不误触游戏）；跳过后遮罩消失、系统恢复正常交互；探险到点结算会暂时挂起遮罩（先弹结算，收下后引导跳到下一步）。
