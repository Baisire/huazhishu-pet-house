# 正式版

测试版验证通过的效果，才允许进入这里，并正式推送到远程仓库。

## 准入条件

进入正式版前逐条确认：

1. 对应决策项在 [待拍板决策跟踪](../docs/decisions/待拍板决策跟踪.md) 中已到"已验证"，并由项目所有者定稿；
2. 设计文档已同步为定稿值，文档版本号递增；
3. 无调试代码：调试色条、自检闪屏、测试按钮全部移除或仅 dev 构建注入；
4. 存档可迁移：旧版本存档能无损升级，导出存档码可用；
5. 构建可复现：从干净环境拉取后可构建通过；
6. 提交信息与版本号规范，tag 为 `release-vX.Y.Z`。

## 版本号

语义化版本：`release-v<主>.<次>.<修订>`。

- 主版本：对外发布里程碑（M3 上线为 v1.0.0）；
- 次版本：新增玩法或内容；
- 修订：修 bug、调数值。
