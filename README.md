# 花枝鼠养成小屋

横屏全屏、可离线挂机的花枝鼠养成小游戏。测试版按参考图方向验证暖色像素风与全屏小屋场景；首发平台暂定抖音小游戏（个人主体，纯广告 IAA），第二出口 H5。

当前阶段：立项评审 → 测试版开发准备。游戏代码尚未开始写。

## 两条线：测试版与正式版

| | 测试版 `test/` | 正式版 `release/` |
| --- | --- | --- |
| 形态 | 纯 HTML/JS 可玩原型 | 按定稿决策落地的正式工程 |
| 改动频率 | 高，随时改 | 低，只接受验证过的效果 |
| 版本管理 | `test-vNNN` tag，只保留最近 3 个 | `release-vX.Y.Z` tag，永久保留 |
| 入库 | 在 `test` 分支上提交 | 合入 `main`，正式推送到远程仓库 |

一句话规则：**测试版跑通的效果，才允许成为正式版的下一版本。**

## 分支与 tag

- `main`：正式线。不直接改，走分支 + Pull Request 合入，打 `release-vX.Y.Z` tag。
- `test`：测试线。日常改动直接提交，达到可玩节点打 `test-vNNN` tag。
- 功能分支：从 `main` 切出，命名与提交信息规范见 [合作开发说明.md](file:///d:/trae/项目23：花枝鼠养成小屋/合作开发说明.md) 第 6 节。

## 测试版一轮迭代怎么做

```bash
# 1. 在 test 分支改动 test/ 下的文件
git switch test

# 2. 达到一个可玩节点，打 tag（序号递增）
git tag test-v001
git push origin test-v001

# 3. 轮转：只保留最近 3 个 test tag
powershell -ExecutionPolicy Bypass -File tools\rotate-test-tags.ps1 -Remote

# 4. 验证通过后并入正式线，成为 release 的下一版本
```

轮转脚本默认保留 3 个，可加 `-DryRun` 先看会删哪些。
