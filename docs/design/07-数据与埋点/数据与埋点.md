## 7.1 北极星指标

**北极星：人均日有效激励视频观看次数（VA/DAU）。**

选择理由：纯 IAA 产品的收入 ≈ DAU × VA/DAU × eCPM，eCPM 不可控、DAU 是结果，唯一可运营的杠杆就是"每个用户每天看几次"。它同时约束了留存（看不下去说明体验坏了）和变现（看得多说明点位设计有效）。

护栏指标（任一恶化即视为北极星虚高）：次日留存、7 日留存、单用户日均会话时长、举报率、广告关闭率。

## 7.3 漏斗与口径

激活漏斗：`app_launch → tutorial_complete → 首次 stat_action → 首次 expedition_claim → 首次 ad_show → 次留`

| 指标      | 口径                               | 目标（经验值） |
| ------- | -------------------------------- | ------- |
| 教程完成率   | tutorial\_complete / app\_launch | ≥80%    |
| 首日探险参与率 | 首日 expedition\_start ≥1 的用户 / 新增 | ≥70%    |
| 广告触发转化率 | ad\_show / ad\_trigger           | ≥55%    |
| 广告完播率   | ad\_reward / ad\_show            | ≥90%    |
| 次日留存    | 自然日回访 / 新增                       | ≥30%    |
| 7 日留存   | 第 7 自然日回访 / 新增                   | ≥10%    |
| VA/DAU  | 当日 ad\_reward 次数 / 当日 DAU        | 5–8     |

留存统一按**自然日**计算，不按 24 小时滚动窗口，避免与平台后台口径打架。
